# 秋招投递管理

这是一个用来记录和管理秋招投递进度的本地网页应用。

## 运行方式

1. 双击 `run_app.bat`
2. 浏览器访问：
   - http://localhost:8000
3. 在页面中新增公司、岗位、城市和阶段即可

## 功能

- 记录投递公司和岗位
- 记录城市、方向、投递渠道
- 更新阶段：已投简历 / 简历挂 / 一面 / 一面挂 / 二面 / 二面挂 / offer / 拒绝
- 记录面试经验和备注
- 查看各城市的投递情况
- 统计总投递数、进行中、offer 等数据

## 数据保存

数据保存在浏览器本地 localStorage 中，刷新页面不丢失。

## 说明

如果 `run_app.bat` 没有启动，请确认 Python 环境存在，或修改脚本中的 Python 路径。
